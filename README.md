# VolCtrl - Windows 键盘音量控制工具

一款 Windows 系统下的音量控制工具，通过键盘快捷键快速调节音量。

## 功能特性

- 🎹 快捷键控制：默认 Win+Alt+↑/↓ 调节音量，Win+Alt+M 静音
- ⚙️ 自定义热键：托盘菜单里随时改键，配置自动保存
- 📊 屏幕底部实时显示音量条
- 🔄 自动跟随默认播放设备切换（切换声道/耳机、拔插设备后无需重启）
- 🚀 开机自启动
- 📍 系统托盘驻留
- 🔔 音量变化通知
- 💻 高稳定性热键（使用 pynput 库）

## 系统要求

- Windows 10/11
- Python 3.8+
- 需要管理员权限运行（确保热键稳定工作）

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

或手动安装：

```bash
pip install pycaw pynput pystray pillow comtypes win10toast
```

### 运行程序

```bash
python VolCtrl.py
```

> ⚠️ **重要**：请以管理员权限运行程序，以确保热键稳定工作。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Win + Alt + ↑ | 增加音量 |
| Win + Alt + ↓ | 减少音量 |
| Win + Alt + M | 静音/取消静音 |
| 右键托盘图标 | 打开菜单 |

以上为默认值，可在托盘菜单「设置热键…」中自定义。

## 自定义热键

### 通过托盘菜单（推荐）

1. 右键托盘图标，选择「设置热键…」
2. 点击要修改的动作后面的「修改」按钮
3. 直接按下新的快捷键组合（至少包含一个修饰键，按 Esc 取消）
4. 点击「保存」，新热键立即生效并写入配置文件

> 💡 组合键支持 Ctrl / Alt / Shift / Win 四个修饰键，主键可以是字母、数字、方向键、F1-F12、空格等。
> 由于程序使用全局键盘钩子捕获按键，即使焦点不在本程序上也能录入组合键。

### 通过配置文件

配置文件位于 `%APPDATA%\VolCtrl\config.json`，可以直接编辑：

```json
{
  "hotkeys": {
    "volume_up": "ctrl+alt+up",
    "volume_down": "ctrl+alt+down",
    "mute": "ctrl+alt+m"
  }
}
```

修改后右键托盘图标选择「重新加载热键配置」即可生效（或重启程序）。

- 写法不区分大小写，`control`、`cmd`、`super` 等别名会自动规范化
- 普通按键必须搭配至少一个修饰键，避免打字时误触发；F1-F12 和媒体键可以单独使用
- 配置无效时会自动回退到默认热键，并在控制台输出提示

## 音量条说明

- 调节音量时，屏幕底部会显示音量条
- 颜色提示：
  - 🟢 绿色：低音量 (0-30%)
  - 🔵 蓝色：中音量 (30-70%)
  - 🟠 橙色：高音量 (70-100%)
  - ⚪ 灰色：静音状态
- 点击音量条可将其隐藏
- 音量条 1.5 秒后自动消失

## 常见问题

**Q: 热键失效怎么办？**
A: 请确保以管理员权限运行程序。如果仍有问题，可右键托盘图标选择"重新加载热键配置"，或重新设置热键。

**Q: 自定义热键不生效？**
A: 确认组合键中至少包含一个修饰键（Ctrl/Alt/Shift/Win）；如果是在配置文件中修改的，需要右键托盘选择"重新加载热键配置"。另外请避开已被系统或其他软件占用的组合键（如 Win+L）。

**Q: 手动切换了播放设备/声道后，音量快捷键没反应？**
A: 每次调节前程序都会检测当前默认播放设备，切换后自动跟随新设备，一般无需重启。如果仍无效，请确认新设备已被设为 Windows 默认播放设备。

**Q: 如何卸载？**
A: 运行 `uninstall.bat` 或手动删除开机启动项。
